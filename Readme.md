# My Configuration

Welcome to my personal configuration repository. This repo holds my different operating system configurations, dotfiles, wallpapers, themes, etc. It is organize into branches, each dedicated to a specific platform or purpose.

 
## Repository Structure

The repo is split into several branches to keep configurations clean and separate:

**`master`** - Contains the only `Readme.md` file. Serves as a landing point for the repository.

**`linux`** - All congigurations files for my Linux setups (e.g. .zshrc, themes, fonts, icons, terminal backgrounds)

**`windows`** - Congiguration files and power shell scripts (e.g. PowerShell Profile, cursor, etc)

**`wallpaper`** - A collection of wallpapers used across all of my devices.
[view branch --> https://github.com/GeistAsim/configurations.git]

## Getting Started

To use these configurations, clone the repository and switch to the desired branch:

```bash
git clone https://github.com/GeistAsim/configurations.git
cd configurations
git checkout <branch name> #e.g. linux, wallpaper or windows
```
